# Mont Homebrew tap

Homebrew distribution for the [Mont CLI Developer Preview](https://github.com/usemont/mont-cli).

The first signed public release is awaiting publication approval; no installable formula is published yet. Once the release and formula are available:

```sh
brew install usemont/tap/mont
```

Packages must have Developer ID signing, Apple notarization, SHA-256 checksums, approved Nauchu AB proprietary preview terms, and third-party notices. The SDK and engine source are not distributed here.
