# Mont CLI

Install: `brew install usemont/tap/mont`.

Upgrade: `brew update && brew upgrade usemont/tap/mont`.

Requires macOS ARM64. Homebrew installs external FFmpeg/ffprobe separately; neither is shipped or linked into Mont.

Check `mont --version`, then run `brew test usemont/tap/mont` for the installed project and video workflows.

[Binary releases and preview terms](https://github.com/usemont/mont-cli/releases).
